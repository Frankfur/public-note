  ```
       gap: 2rem;  /* 子元素间距 */
     }

     @media (max-width: 768px) {
  ```

- **CSS选择器复习**：
  ```
  为什么要学选择器？
  → 准确选中你要修改的元素
  → 避免冲突和副作用
  
  选择器优先级（Specificity）：
  - 元素选择器 (div) = 1分
  - 类选择器 (.button) = 10分
  - ID选择器 (#header) = 100分
  - 内联样式 (style="") = 1000分
  
  规则：
  - 尽量用类选择器（可重用，特异度适中）
  - 避免用ID选择器（特异度太高）
  - 从不用!important（是代码坏味道）
  ```

- **Flexbox完全指南**：
  ```
  容器属性（Flex Container）：
  - display: flex
  - flex-direction: row | column
  - justify-content: center | space-between | space-around
  - align-items: center | flex-start | flex-end
  - gap: 1rem
  - flex-wrap: wrap

  项目属性（Flex Item）：
  - flex: 1  /* flex-grow, flex-shrink, flex-basis缩写 */
  - align-self: center
  - order: 1
  
  PM视角：
  → 布局灵活性：手机、平板、PC都要适配
  → 性能：Flexbox比float快
  → 易维护：CSS代码更清晰
  ```

```javascript
// 需求：
```

#### Day 8 (Wednesday)：异步编程基础

**问题导入**：
```
为什么需要异步编程？

场景1：网络请求
const response = fetch('api.example.com/data');
console.log(response);  // 打印什么？
→ 问题：请求还没完成，code就往下执行了

场景2：延时操作
console.log('开始');
setTimeout(() => console.log('等待2秒后'), 2000);
console.log('结束');
→ 输出顺序：开始 → 结束 → 等待2秒后

为什么？
→ 因为JavaScript是单线程的
→ 长时间操作会阻塞UI
→ 异步允许"继续往下执行，等结果好了再处理"
```

**异步编程三种方式**：
```
方式1：Callback（回调，已过时）
function fetchData(callback) {
  setTimeout(() => {
    callback({name: 'John'});
  }, 1000);
}

fetchData(function(data) {
  console.log(data); // 1秒后打印
});

问题：嵌套多了就是"Callback Hell"

方式2：Promise（2015年引入）
function fetchData() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      resolve({name: 'John'});
    }, 1000);
  });
}

fetchData()
  .then(data => console.log(data))
  .catch(error => console.error(error));

优点：链式调用，避免嵌套

方式3：Async/Await（2017年引入，最现代）
async function getData() {
  try {
    const data = await fetchData();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

优点：代码看起来像同步，最易读
```

**学生任务**：
```
用Async/Await改写待办应用：
1. 从假的API获取初始待办列表
2. 点击添加时，模拟保存到服务器（延迟1秒）
3. 添加成功提示

示例：
async function saveTodo(text) {
  try {
    // 模拟API调用
    await new Promise(resolve => setTimeout(resolve, 1000));
    console.log('保存成功');
  } catch (error) {
    console.error('保存失败');
  }
}
```

### Week 3-4：React基础

#### Day 11 (Monday)：React入门 + 组件概念

**问题导入**
```
传统方式的问题：
- 页面复杂时，JavaScript代码混乱
- 数据变化需要手动更新DOM
- 代码难以复用

解决方案：React
- 组件化：分解为小的、可复用的部分
- 声明式：你说"我要什么样"，React负责"怎么做"
- 单向数据流：数据 → 组件 → UI

类比：
传统方式 = 一张白纸，用笔一笔笔画
React方式 = 一本积木书，组合不同的积木
```

**Guided Practice项目**：第一个React组件
```jsx
// 安装React
npx create-react-app my-first-react-app
cd my-first-react-app
npm start

// 创建一个简单组件
function Welcome() {
  return <h1>Hello, React!</h1>;
}

// JSX是什么？
// JSX = JavaScript + XML
// 让你在JS中写HTML一样的语法
const element = <h1>Hello</h1>;
// 实际被编译为：
// const element = React.createElement('h1', null, 'Hello');
```

**概念讲解**：
```
组件（Component）：
- 可复用的代码块
- 返回一些UI

函数组件 vs 类组件：
function Welcome(props) {
  return <h1>Hello {props.name}</h1>;
}

类组件（旧方式，了解即可）：
class Welcome extends React.Component {
  render() {
    return <h1>Hello {this.props.name}</h1>;
  }
}

Props（属性）：
- 父组件传给子组件的数据
- 只读的（不能修改）
- 类似HTML的属性（<img src="" alt="">）

Props示例：
<Welcome name="John" age={30} />

function Welcome(props) {
  console.log(props); // { name: "John", age: 30 }
  return <h1>Hello {props.name}, {props.age}</h1>;
}
```

#### Day 12 (Tuesday)：State和Hooks

**State vs Props对比**：
```
Props：
├─ 父传子的数据
├─ 只读，不能修改
└─ 跨组件通信

State：
├─ 组件自己的数据
├─ 可修改（通过setState）
└─ 修改会重新渲染UI

类比：
Props = 函数的参数
State = 函数内的局部变量
```

**Guided Practice**：计数器应用
```jsx
import { useState } from 'react';

function Counter() {
  // 使用State Hook
  const [count, setCount] = useState(0);
  // count = 当前值
  // setCount = 更新函数
  // 0 = 初始值

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        增加
      </button>
      <button onClick={() => setCount(count - 1)}>
        减少
      </button>
    </div>
  );
}
```

**Hooks讲解**：
```
Hook = 在函数组件中"钩入" React特性的方式

最常用的两个Hook：

1. useState：管理状态
   const [value, setValue] = useState(initialValue);
   
   什么时候用？
   → 需要根据用户交互改变UI
   → 例如：计数、输入框的值、开关状态

2. useEffect：处理副作用（side effects）
   副作用 = 组件外的事情
   ├─ 网络请求
   ├─ 定时器
   ├─ 修改DOM（不用React）
   └─ 订阅事件

   useEffect(callback, dependencies);
   
   例如：
   useEffect(() => {
     // 组件挂载时获取数据
     fetch('/api/data').then(res => res.json()).then(data => {
       setData(data);
     });
   }, []); // [] 表示仅在组件挂载时执行
```

**学生独立项目**：待办应用（React版本）
```jsx
function TodoApp() {
  const [todos, setTodos] = useState([]);
  const [input, setInput] = useState('');

  function handleAdd() {
    if (!input) return;
    setTodos([...todos, { id: Date.now(), text: input, done: false }]);
    setInput('');
  }

  function handleToggle(id) {
    setTodos(todos.map(todo => 
      todo.id === id ? {...todo, done: !todo.done} : todo
    ));
  }

  function handleDelete(id) {
    setTodos(todos.filter(todo => todo.id !== id));
  }

  return (
    <div>
      <input 
        value={input} 
        onChange={(e) => setInput(e.target.value)}
        onKeyPress={(e) => e.key === 'Enter' && handleAdd()}
        placeholder="输入待办项"
      />
      <button onClick={handleAdd}>添加</button>
      
      <ul>
        {todos.map(todo => (
          <li key={todo.id}>
            <input 
              type="checkbox" 
              checked={todo.done}
              onChange={() => handleToggle(todo.id)}
            />
            <span style={{textDecoration: todo.done ? 'line-through' : 'none'}}>
              {todo.text}
            </span>
            <button onClick={() => handleDelete(todo.id)}>删除</button>
          </li>
        ))}
      </ul>
    </div>
  );
}
```
