2026-10-09 密码生成器
key takeaways:

<ul>
<li>如何将一组array,进行随机打乱？要求：
  1. 必须是随机的。
  2. 包含所有类型的字符。
  3. 单个字符只能出现一次； 
</li>
<li>2. 代码复用：既然生成 密码1，与密码2的生成逻辑一致，那么可以将生成密码的逻辑封装成一个函数，然后调用这个函数即可。</li>
<li>3. 生成密码的逻辑：生成密码的逻辑，可以分为两部分： 
   一部分是生成密码的字符，
   一部分是生成密码的长度,生成密码的字符，必须是包含大小写字母、数字、特殊字符;
<li>
4. 生成密码的长度，可以是随机的，但不能小于8位，也不能大于21位。
</li>
<li>
修正后的代码还是有问题，因为没有保证字符只出现一次，所以生成的密码可能会有重复的字符。需要对字符进行去重处理。建议的方案：提取某个字符，即从数组中去除，再随机打乱数组，最后再将数组中的字符，拼接起来，就是生成的密码。
</li>
