Fisher–Yates 洗牌算法

从后往前，每一轮从“还没确定”的牌里随机抽一张放到当前位置，抽完就固定下来。

待洗牌区（从这里随机抽）已确定区
i：当前要确定的位置 j：随机抽到的位置 已确定，不再移动

算法代码

for (let i = n - 1; i > 0; i--) {  const j = randInt(0, i);    // 0 ≤ j ≤ i  [a[i], a[j]] = [a[j], a[i]]; // 交换}

    为什么这样洗是公平的

    最后一个位置有 n 种选择，倒数第二个有 n−1 种……一共 n! 条路径，每种排列恰好对应一条，所以每种结果的概率都是 1/n!。

    常见错误是每一轮都在整个数组里随机交换：这样有 nⁿ 条路径，而 nⁿ 无法被 n! 整除（n≥3），必然有些排列出现得更频繁。
